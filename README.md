# Promise Tracker AI for Odoo (15 – 20)

Never forget what you promised a customer.

**[See screenshots, demo video and pricing →](https://technoversesystems.com/odoo-promise-tracker)**

## Features
- Detects promises in chatter, e-mails, Discuss and WhatsApp ("we will send the quote by Friday")
- Rule detector (English and Roman Urdu) plus optional AI (OpenAI, Gemini or Claude)
- "Track as Promise" on any chatter message, linked to the customer and document
- Due dates, reminders, weekend handling, broken-promise alerts and a daily digest
- Auto-kept when the linked quote, delivery or invoice is done
- Scorecard: % kept and on-time per salesperson and team
